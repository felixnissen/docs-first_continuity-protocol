# Finished Tasks

Discoverability: naming convention `DFC-NNNN_task-slug.md`. This archive is not
indexed file by file. Every member is addressable by its immutable Task ID, and
an archived task is never renamed or moved.
Member state: required. Every member declares a `Status:` line under its title.

An archived task is immutable historical context. It records what was agreed,
what was produced and what was verified, at the time. Current behaviour lives in
`docs/CURRENT_STATUS.md` and `docs/SYSTEMDOC.md`.

Cancelled and superseded tasks are archived here too, with their final status
and a link to whatever replaced them.

The archive currently contains completed DFC-0001 and DFC-0002 at
`DFC-0001_protocol-specification.md` and
`DFC-0002_conformance-validator.md`. Future members follow the same immutable
Task-ID-based naming convention.
